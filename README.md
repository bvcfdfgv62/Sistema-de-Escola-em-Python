# Sistema de Gestão Escolar - Web App 🎓

Este é um sistema moderno de gestão escolar desenvolvido com **Flask**. O projeto foca em uma interface intuitiva e funcionalidades essenciais para o gerenciamento de alunos, notas e desempenho acadêmico.

## 🚀 Funcionalidades

- **Autenticação Segura**: Sistema de login para acesso restrito.
- **Dashboard Interativo**: Visualização de estatísticas gerais da escola.
- **Gestão de Alunos**: Adicione, remova e visualize a lista completa de estudantes.
- **Lançamento de Notas**: Sistema simplificado para registro de avaliações.
- **Boletim Inteligente**: Cálculo automático de médias e status de aprovação.
- **Design Premium**: Interface responsiva e moderna utilizando Vanilla CSS e JavaScript.

## 🛠️ Tecnologias Utilizadas

- **Backend**: Python + Flask
- **Banco de Dados**: SQLite (init_db automatizado)
- **Frontend**: HTML5, CSS3 (Modern UI), JavaScript (Fetch API)
- **Relatórios**: ReportLab (utilitário para geração de PDFs)

## 📦 Estrutura do Projeto

```text
├── app.py              # Ponto de entrada da aplicação Flask
├── routes.py           # Definição das rotas e lógica de negócio
├── db.py               # Camada de persistência e modelos do banco
├── Codigo1/            # Utilitários adicionais (Geração de PDF)
├── static/             # Arquivos estáticos (CSS, JS)
├── templates/          # Templates HTML (Jinja2)
└── requirements.txt    # Dependências do projeto
```

## 🔧 Como Executar

1. **Instale as dependências**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Inicie o servidor**:
   ```bash
   python app.py
   ```

3. **Acesse no navegador**:
   ```
   http://localhost:3000
   ```
